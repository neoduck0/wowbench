# APHELION

A one-shot website built by **Grok 4.6** on high effort, via **Grok Build**, in about 35 minutes from an empty folder.

The initial prompt was:

> Build the craziest website you can build. I want something that makes me go wow.

No framework. No build step. Just HTML, CSS, and WebGL2 shaders — six raymarched worlds, a cinematic gate, and a small generative soundtrack.

## Run it

From this directory:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

Click **enter**. Scroll or use the arrow keys to travel. `?` shows the rest of the controls.
